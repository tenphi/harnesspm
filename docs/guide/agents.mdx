title: For AI agents

---

**In short**

- Run `npx -y @harnesspm/cli` in the folder the person named. In a project that uses harnesspm, it prints the project's report. Elsewhere, it says what the folder is and which command starts each task. Run that command, and do what it prints.
- Never give yourself permissions. Trust and `approve` belong to the person: when harnesspm says that a step waits for a person, report it and wait.
- In a project that uses harnesspm, the managed block in `AGENTS.md` and the skills `harnesspm-import`, `harnesspm-export` and `harnesspm-improve` match the installed version. This site describes the latest one.
- [llms.txt](https://harnesspm.tenphi.me/llms.txt) lists every page of this site with a Markdown copy, and the [specification](https://github.com/tenphi/harnesspm/blob/main/docs/spec/README.md) has every rule behind them.
